# ETS2 Reverse Guidance v0.3.0-preview.5

欧卡 2 的 Windows x64 倒车轨迹辅助。基于 [yyysheng 的 ETS2 Reverse Posture Assistant v0.11.1](https://github.com/yyysheng/ETS2mods/tree/reverse-posture-assistant-v0.11.1/mods/ETS2_Reverse_Posture_Assistant)，以 MIT 许可证公开项目源码。

提供牵引车与第一节挂车轨迹、车头外摆线、挂车预测终点轮廓和车挂夹角趋势。驾驶操作由玩家完成。

本地预览版新增**手动放置目标、规划纯倒车路线和方向盘提示**，尚未完成游戏内操作、路线误差和帧率验收。GitHub 上已发布的 v0.2.2 是此前版本；本预览版的源码与构建包不代表已发布新的 Release。

preview.2 调整目标显示：独立青色框、四角标记、车尾中心十字与朝向箭头；缩小状态文字并提供前后两种阅读方向。该显示修改经过离线线段预览检查，仍需游戏内验收。升级需要同时更新 DLL 与随包资源，保留自己的 INI。

## 下载与安装

从 [Releases](https://github.com/sakuradairong/ETS2-Reverse-Guidance/releases) 选择对应游戏版本的 `ETS2-Reverse-Guidance-v<版本>-windows-x64.zip`。v0.2.1 没有 1.61.1.9 配置；本地预览构建包位于 `dist/`，线上发布状态以 Releases 页面为准。`SHA256SUMS.txt` 提供压缩包校验值。解压后：

1. 完全退出欧卡 2。若安装过旧版，备份原来的 DLL、INI 与 `ets2_reverse_posture_tmp` 资源目录；在模组管理器停用原版 Reverse Posture Assistant `.scs`，避免重复轨迹。
2. 把 `plugins/ETS2ReverseEntityRuntime.dll` 和 INI 放到游戏目录的 `bin/win_x64/plugins/`。目录不存在时创建。升级时可以保留自己的 INI。
3. 把 `home/ets2_reverse_posture_tmp/` 放到实际游戏用户资料目录，例如 `Documents/Euro Truck Simulator 2/ets2_reverse_posture_tmp/`。使用 OneDrive 或 `-homedir` 时，以实际目录为准；不额外创建物理 `home` 文件夹。
4. 启动单机存档，挂倒挡检查地面提示。DLL 需要 Microsoft Visual C++ 2015–2022 Redistributable x64。

回退时完全退出游戏并恢复备份。首次安装后的卸载只需移除本插件 DLL/INI 与本插件资源目录；不要移除其他插件或存档。

## 提示含义

| 显示 | 含义 |
| --- | --- |
| 蓝色轨迹 | 牵引车后角路径、转向外摆前角路径；低速前拉拉正时显示牵引车前角轨迹；目标模式含前拉段时亦用蓝色标示前拉路线 |
| 橙色轨迹 | 第一节挂车后角路径 |
| 淡色参考走廊 | 沿挂车当前朝向笔直向后延伸的参考走廊，与转向预测曲线形成直观对照 |
| 淡橙色终点轮廓 | 保持当前实际轮角、牵引车继续倒退指定距离时的挂车预测姿态 |
| 车头旁夹角标记 | 当前车挂夹角、倒退 1 米（或前拉预测终点）的趋势与折刀临界刻度：绿色收直、橙色扩大/临界告警、淡色变化小 |

当车挂夹角逼近由轴距、鞍座偏置与实测挂车轴距算出的理论折刀临界角时，夹角标记会标出临界刻度；在未启用手动目标时，车侧还会复用已有中文提示牌给出实时脱困建议（警告区且持续折刀时提示 `左打` / `右打` 反打，超过临界角时提示 `向前调整`）。启用 `session_latch=1` 后，倒车途中短时切空挡或低速前进拉正（≤2.8 m/s、≤12 m、≤20 s）不会立即隐藏引导，并会在前进拉正时展示前移拉直预测（挂车轨迹变绿表示夹角正在收直）。

低速、平坦路面且实际轮角数据可用时，默认显示 5 米预测。超过 5 km/h 后逐渐缩短，到 10 km/h 时缩到 2 米，并隐藏终点轮廓。估计接地坡度超过 4° 时同样收短；达到 10° 时缩到 2 米。实际轮角或车速不可用时保留 2 米轨迹并隐藏终点。挂倒挡但实际向前滚动超过 0.3 m/s 时隐藏提示。以上阈值是保守显示策略，尚未经过游戏内误差校准。

预测使用固定轮角、无侧滑的低速运动学模型。它不读取障碍物，也没有模拟轮胎摩擦、载重惯性和坡道溜车动力学；轮廓尺寸由车轮/挂钩配置估算，不能当作精确碰撞边界。当前只显示第一节挂车，多挂组合的完整扫掠范围不受保证。

## 配置

编辑与 DLL 同目录的 `ETS2ReverseEntityRuntime.ini` 后完全重启游戏：

```ini
[guidance]
enabled=1
endpoint_outline=1
front_swing=1
articulation_indicator=1
trailer_corridor=1
session_latch=1
jackknife_cues=1
prediction_distance_cm=500
corridor_distance_cm=600

[diagnostics]
enabled=0
```

预测距离与挂车参考走廊长度均限制为 200–800 厘米，动态策略只会缩短预测距离。诊断默认关闭；加载及错误信息仍可在 `game.log.txt` 与游戏目录的 `ETS2ReverseEntityRuntime.log` 中查看。

## 指定位置倒车（实验）

适用于单节、无转向轴的普通半挂车，牵引车不得使用接地的后转向轴；需要有效的单挂类型、挂钩、接地车轮、实际前轮转角和轮胎拟合地面数据。缺失数据或未知组合不启用规划。只在估计坡度不超过 4° 的开阔平地、5 km/h 以下尝试；目标位置不包含障碍物或坡道信息。

所有快捷键都要同时按住 **Ctrl + Shift**，只在游戏处于前台时生效，每次按下触发一次；插件不拦截游戏按键。若有键位冲突，在 `[target]` 中修改十进制 Windows 虚拟键码，或设 `enabled=0` 关闭目标功能。

| 快捷键（均加 Ctrl + Shift） | 操作 |
| --- | --- |
| F8 | 停车后开启/关闭目标；初始目标在估计挂车尾部后方 8 米。未停车或数据不足时不开启，车侧仍显示停车或检查数据 |
| ← / → / ↑ / ↓ | 编辑时按牵引车坐标左右/前后移动目标，每次 0.5 米（同时按住 Alt 为粗调 2.0 米） |
| Page Up / Page Down | 编辑时将目标朝向减少/增加 5°（同时按住 Alt 为粗调 15°） |
| Enter | 停车并挂倒挡，确认目标并开始搜索；搜索期间保持车身和方向盘不动 |
| Backspace | 停车后重新编辑目标；确认可重新搜索 |
| Delete | 清除目标与路线 |

使用外部视角放置目标框。目标由**估计挂车尾部中心位置和挂车朝向**共同定义；目标框为轮组/挂钩估算的挂车外形，尾部短箭头指向车尾方向。它不读取游戏绿色交货框，也不能判断游戏是否接受交货。

目标框固定为青色，通过四个加密的 L 形角标与稀疏侧线标明位置，与浅橙色的实际轮角预测终点区分。框尾中央的十字是目标锚点，外侧箭头指向车尾方向。规划成功后，挂车尾部中心路线也为青色，到位后框变绿。路线不是车辆完整扫掠边界。

牵引车两侧各显示一处简短状态字样，方向相反：右侧朝向车头视角，左侧朝向车尾视角，避免在同一侧堆叠倒置文字；中文字高约 0.9 米，每侧用一个预制文字模型显示，构建和运行无需安装中文字体。状态正常时使用青色，到位使用绿色，需要停车、减速或数据不足时使用浅橙色。它们固定在地面，不会跟随任意相机角度旋转。共用 256 段显示预算，目标框、两侧文字与规划路线最多占 160 段，为实际轮角预测保留至少 96 段，必要时均匀抽稀预测线。

| 字样 | 含义 |
| --- | --- |
| 编辑目标 / 规划中 | 编辑目标 / 正在搜索，请保持停车 |
| 左打 / 右打 | 方向盘继续向左 / 向右调整，与当前实测轮角比较 |
| 回正 / 保持 | 轮角接近回正 / 保持当前轮角；仍需看路线手动驾驶 |
| 停车 / 减速 | 停车、挂倒挡或停车后重算 / 减速至 5 km/h 以下并停车重算 |
| 已到位 | 估计车尾位置误差不超过 0.6 米、朝向误差不超过 4°、车挂夹角不超过 20°，且车速低于 0.05 m/s；不要求保持倒挡 |
| 搜索超限 | 搜索预算耗尽，不表示目标物理上不可达；可缩短路线或向前调整起点再试 |
| 向前调整 | 目标超出范围，或在当前离散搜索范围内未找到路线；建议向前摆正后再试 |
| 检查数据 | 数据缺失、坡度超限、轮角/夹角超限，或车型不受支持；详情见 `[reverse-target]` 日志 |

规划使用分帧的加权 Hybrid A*，支持在纯倒车不可达时自动加入最多一次起始前拉摆正段（`allow_pullup=1`，前拉距离上限 12 米，带换挡代价优先保留纯倒车方案）。前拉段以蓝色绘制、换挡点以绿色十字标示、倒车段以青色绘制；挂倒挡启动带前拉的路线时会提示 `向前调整`，挂前进挡跟随前拉段至绿色切换点提示 `停车`，停车换倒挡后自动接续青色倒车引导。保留车头朝向、挂车朝向和轮角状态；每次按 5 厘米积分，轮角采用渐变。采用保守的模型限制：搜索指令的前轮角为 ±30°，实测起始轮角允许到 ±50° 并在路线中渐变回去；轮角变化不超过 0.24 rad/m、车挂夹角不超过 55°、总行程不超过 40 米；搜索最多展开 18,000 个节点，保存最多 80,000 个节点，每帧最多处理 48 项且检查 1.5 ms 时间片。这是有界搜索，不保证找到所有可行路线，也不保证最短路径；时间片不等同于已经验证的帧率表现。车速低于 0.05 m/s 时，搜索按已用时间放宽平移容差，缓慢蠕动不会打断搜索；明显的转向或朝向变化仍会要求停车重算。方向盘提示结合前方约 2 米参考轮角与基于挂车运动学的反馈线性化闭环纠偏，在轻微走偏时持续引导拉回；共用 256 段预算在目标模式下按语义分层保留（优先完整保留夹角、走廊与挂车轨迹，不把紧凑指示抽稀为碎点）。

位置偏离超过 1.5 米，或牵引车朝向偏离超过 26°、挂车朝向偏离超过 18°，会清除旧建议，提示停车后从当前姿态重新规划。数据暂时失效时隐藏路线，恢复后停车重算；换车、切换场景、断开挂车、几何变化或检测到明显位置跳变时清除目标。目标在正常驾驶中保持世界坐标不变。

驾驶员负责方向盘、油门、制动和挡位。路线只反映低速无侧滑几何模型：不会检测碰撞、侧滑、载重惯性或远处地面，也未标定方向盘传动比与实际转向速度。请从空旷单机场地开始验收。

## 从源码构建

需要 Windows、Visual Studio 2022 / Build Tools（v143 C++ 工具和 Windows SDK）、Python 3.10+。依赖头文件、MinHook 源码和必要资源已包含在仓库中，不依赖作者的下载目录。

```powershell
git clone https://github.com/sakuradairong/ETS2-Reverse-Guidance.git
cd ETS2-Reverse-Guidance
powershell -ExecutionPolicy Bypass -File .\Build.ps1
```

脚本定位 MSBuild，构建 DLL 与三组测试，验证资源引用链，再在 `dist/` 生成发布 ZIP 和 SHA256SUMS。每次打包使用新的输出目录；再次打包前将旧 `dist/` 重命名或移走。构建过程不会安装插件或修改游戏/存档。

可使用 `./Build.ps1 -GameExecutable '实际游戏目录/bin/win_x64/eurotrucks2.exe'` 对本机文件增加只读检查：根据实际 SHA256 选择配置，验证 Hook 和辅助函数特征，以及牵引车/挂车渲染调用。该检查不会启动游戏，也不能证明运行时显示正常。

如需从原始下载包重新提取资源，可设置 `ETS2_REVERSE_UPSTREAM` 并在不含仓库资源的副本中运行资源准备工具；常规构建直接使用随仓库提供的基础资源并生成新增颜色。
